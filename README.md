### Featured projects

- ✈️ **[disruption-api](https://github.com/1lauraog15-cloud/disruption-api)** — backend practice project modelled on an airline operations control centre (synthetic data): Flask REST API with Pydantic validation and API-key auth, SQLAlchemy 2.0 on PostgreSQL with Alembic migrations, a Celery worker that estimates impact and propagates delays along an aircraft rotation, OpenAPI docs, Docker Compose, and GitHub Actions CI (lint, strict typing, security scans, migrations on PostgreSQL, tests, and an end-to-end run of the container stack).
- 🎸 **[flamenco-classifier](https://github.com/1lauraog15-cloud/flamenco-classifier)** — automatic classification of flamenco *palos* (soleares, seguiriyas, bulerías, alegrías) from audio. Features are grounded in music theory rather than picked blind — Phrygian mode and the Andalusian cadence, position of the metric close within the 12-beat compás — and fed to a Random Forest: cross-validated **F1-macro 0.645**. [**Live demo**](https://web-production-aad2f.up.railway.app) — upload a track and get the predicted palo with its probabilities.
- 🎤 **[cante-embeddings](https://github.com/1lauraog15-cloud/cante-embeddings)** — embeddings of a *cantaor*'s interpretive identity (who is singing, not which palo), built by fine-tuning pretrained OpenL3 features with a triplet-loss projection head. Closed-set pairwise verification: **AUC 0.80**, with the small-sample limitations documented rather than glossed over.
- 🔍 **[Customer Segmentation with Clustering](https://github.com/1lauraog15-cloud/customer-segmentation-clustering)** — *course mini-project*: unsupervised ML on a 951K-row e-commerce dataset; K-Means + hierarchical clustering, PCA/t-SNE, translated into a marketing strategy.
